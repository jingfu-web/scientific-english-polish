# How source advice becomes a usable rule

The supplied teaching materials mix robust principles, personal preferences, venue conventions, and intentionally flawed examples. User instructions and supplied venue requirements take precedence over optional preferences; never mislabel a preference as grammatical necessity or let style silently change scientific meaning.

| Source advice | Treatment in this skill |
|---|---|
| Never start with Because/And/But | No universal ban. Ensure complete syntax and appropriate formality. A user-requested house style may prefer alternatives. |
| Use since instead of because | Choose by intended emphasis and possible temporal ambiguity, not substitution rules. |
| Restrictive clauses must use that | Consider English variety and venue. Preserve restrictive meaning and punctuation; do not call all restrictive which clauses errors. |
| Use present tense throughout | Select tense by function and style; completed methods/results need not become present tense. |
| Do not mix voices; avoid first person | Keep agency and information flow clear. Follow an explicit house convention if supplied. Third person is not synonymous with passive voice. |
| At most five acronyms; short acronyms only | Minimize reader burden without fixed quotas or invented renaming. |
| Keywords must be singular | Prefer established indexing terms, including conventional plural terms. |
| Paragraphs must be under ten lines; no one-sentence paragraphs | Evaluate unity and readability, not layout-dependent counts. |
| Titles must be 10–12 words or under 100 characters | Aim for accuracy and brevity; enforce only a real target limit. |
| Replace iff with if in definitions | Do not apply mechanically; preserve mathematical equivalence and direction. |
| Use only one empty-set command | Valid notation and existing macro conventions govern. |
| Reference list should be alphabetical / IEEE-style | These source suggestions conflict. Follow the actual venue and existing citation system. |
| Avoid difficult-to-find or Chinese references | Assess relevance and traceability; do not discard a valid source because of language. |
| Use impressive alternatives for ordinary verbs | Prefer clear `present`, `develop`, `show`, or `describe` when accurate; do not force `excogitate` or `adumbrate`. |
| Polite comparative criticism | Keep criticism evidence-based and civil; hedging must not conceal a demonstrated error or invent superiority. |

External calibration checked on 2026-10-11:

- [Cambridge: As, because or since](https://dictionary.cambridge.org/grammar/british-grammar/because) explicitly allows a because-clause at the beginning of a complete sentence.
- [APA: Verb tense](https://apastyle.apa.org/style-grammar-guidelines/grammar/verb-tense) distinguishes recommended tenses across manuscript functions. This is evidence against a universal present-tense rule, not a requirement that every engineering paper follow APA.

When exact contemporary journal compliance matters, consult supplied current instructions or verify the journal's official guidance. Ordinary editing should not become an unnecessary web-research task.
